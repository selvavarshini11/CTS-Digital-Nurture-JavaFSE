# Bootstrap 5 Exercises

Complete exercise files for all 19 Bootstrap 5 topics.

## How to use
1. Open any `.html` file directly in your browser
2. OR use Live Server in VS Code for auto-refresh

## Topics Covered
- Grid, Flexbox, Typography, Forms, Buttons
- Navbar, Cards, Spacing, Colors, Display
- Borders, Positioning, Icons, JS Plugins, Sass
